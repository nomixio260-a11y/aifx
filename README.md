# AIFX: 為替チャート予測

主要7通貨ペア (USD/JPY, EUR/JPY, GBP/JPY, AUD/JPY, EUR/USD, GBP/USD, AUD/USD) の日足データを取得し、
6つの予測モデルで最大20営業日先までの値動きを予測するプログラムです。予測はブラウザで見られるダッシュボード (HTML) として出力されます。

- ローソク足チャートに予測線と予測レンジ (50%・80%・95%) を重ねて表示
- 翌営業日・5・10・20営業日後の予測値、変化幅 (pips)、上昇確率
- 過去1年のバックテスト (ウォークフォワード検証) で、各モデルの誤差・方向的中率・ランダムウォーク比の改善率を表示
- RSI・移動平均・MACD・ボリンジャーバンドによるテクニカル判断
- 今のチャート形状に似た過去の局面を表示

## セットアップ

```bash
pip install -e ".[dev]"      # numpy, pandas (+ pytest)
```

Python 3.10 以上が必要です。

## 使い方

```bash
# ターミナルに予測を表示
aifx forecast USDJPY EURUSD

# ダッシュボードを site/index.html に生成 (全7ペア)
aifx build

# 生成してローカルで配信。--refresh 60 で60分ごとにデータを取り直す
aifx serve --port 8000 --refresh 60

# ネットワークなしで動作確認 (乱数で作った価格を使用)
aifx build --synthetic --pairs USDJPY
```

主なオプション:

| オプション | 説明 |
|---|---|
| `--pairs USDJPY,EURUSD` | 対象ペア (`all` で全ペア) |
| `--horizon 20` | 予測する営業日数 |
| `--years 5` | 取得する履歴の年数 |
| `--offline` | `data/cache/` のキャッシュだけで計算 |
| `--fragment PATH` | `<html>` ラッパー無しのHTML断片も出力 (埋め込み用) |

`site/forecast.json` には、ダッシュボードに表示している全データ (履歴・予測・検証結果) が入っています。

## データ

日足OHLCは Yahoo Finance から取得します。取得できない場合は欧州中央銀行の参照レート (Frankfurter API) に切り替えます。
その場合は1日1つのレートしかないため、始値・高値・安値は終値と同じ値になります。取得したデータは `data/cache/` に保存されます。
最新の足は取得時点の値で、確定前の場合があります。

## モデル

すべて対数価格上で動き、予測のたびにその時点までのデータだけで学習し直します。

| キー | モデル | 内容 |
|---|---|---|
| `rw` | ランダムウォーク | 最新値がそのまま続く。基準モデル |
| `drift` | ドリフト | 直近1年の平均変化率を延長 |
| `holt` | 指数平滑 (減衰トレンド) | Holt法。α・β・φ をグリッド探索で推定 |
| `ar` | 自己回帰 AR(p) | 日次リターンのAR。次数をAICで選択 (ARIMA(p,1,0) 相当) |
| `ridge` | リッジ回帰 | モメンタム・移動平均乖離・ボラティリティから各日数先のリターンを直接予測 |
| `knn` | パターン類似 (k近傍) | 直近20日の値動きの形が近い過去局面の「その後」を平均 |
| — | アンサンブル | 上記を、過去の予測誤差 (MSE) の逆数で重み付けした平均。チャートの予測線 |

**予測レンジ:** 日次リターンのEWMAボラティリティ (λ=0.94) が長期ボラティリティへ徐々に戻ると仮定して、
各日数先の標準偏差を求め、正規分布の 50%・80%・95% 区間を描いています。上昇確率も同じ分布から計算しています。

**バックテスト:** 直近約250営業日について、5営業日ごとに「その日までのデータだけ」で予測を作り、実際の値と比較します。
アンサンブルの重みも、その時点までに答えが出ていた誤差だけで決めています (先読みなし)。
ダッシュボードには、80%レンジに実際の値が入った割合 (カバー率) も表示します。

為替レートはランダムウォークに近いため、どのモデルもこれを大きく上回ることはできません。
ランダムウォーク比の改善率がマイナスのモデルは、その期間では予測しない方が誤差が小さかったことを意味します。

## 構成

```
aifx/
  data.py         価格の取得・キャッシュ・フォールバック
  indicators.py   SMA / RSI / MACD / ボリンジャー / ATR とテクニカル判断
  models.py       予測モデル
  forecast.py     バックテスト・アンサンブル・予測レンジ・レポート生成
  site.py         ダッシュボードHTMLの生成
  cli.py          aifx コマンド
  templates/dashboard.html
tests/            pytest (先読みがないことの検証を含む)
.github/workflows/pages.yml   テスト・ビルド・GitHub Pages への公開
```

```bash
pytest -q
```

## 注意

予測は統計モデルによる参考値で、将来の値動きを保証するものではありません。投資判断はご自身の責任で行ってください。
