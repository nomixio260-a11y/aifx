学習とモデル

判定が済んだ予測の結果だけを使って、4つの値を自動で調整しています。重み: 誤差の小さいモデルを重く使う。信号の採用率: モデルの方向予測にどこまで従うか (実績で有効性が示されるまで0に近い値)。レンジ補正: 80%レンジが実際に約80%当たるよう幅を調整。ニュース係数: ニュース信号で予測をどれだけ動かすか。

過去データでの検証 (シミュレーション)

検証: 実績をごまかせない仕組み

  1. 予測は、結果が分かる前に台帳へ追記されます。各記録は前の記録のハッシュ (SHA-256) を含むため、1件でも書き換え・削除・並べ替えをすると検出されます。
  2. 価格・ニュース・経済指標の生データも追記専用ファイルに保存し、その内容のハッシュを台帳に記録しています。
  3. 予測に使えるのは、起点時刻までに確定した価格と、起点時刻より前に取得済みのニュース・指標だけです。
  4. 判定は対象時刻を過ぎてから、その時点で確定していた価格で行います。対象時刻が来た予測はすべて判定され、都合の悪い予測を飛ばすことはできません。
  5. 予測は定期的に抜き取りで再計算し、当時使えたデータだけで同じ数字が出るかを確かめています (先読みしていれば一致しません)。
  6. 成績は必ず「予測しない (ランダムウォーク)」と同じ予測で比べ、信頼区間と有意性を表示します。
  7. 台帳はGitHubの ledger ブランチに追記のみで保存され、誰でも取得して検証できます。

自分で検証する

git clone https://github.com/nomixio260-a11y/aifx
cd aifx && pip install -e .
git fetch origin ledger && git worktree add state origin/ledger
aifx verify --state state
aifx audit --state state --sample 20 --external

価格: Yahoo Finance (1時間足・日足)。ニュース: Google ニュース検索、各中央銀行、ForexLive。経済指標: Forex Factory カレンダー。
