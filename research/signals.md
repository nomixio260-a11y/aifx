# 売買シグナルの再検証 (約20年分のデータ)

本番の売買プラン ([research/trade.md](trade.md)) の2つのルールを、はるかに長い期間で同じコードのまま検証し直し、少数の改善案を事前に決めた手順で試しました。売買の判定・決済・コスト・スワップは `aifx/trade.py` と `aifx/research_trade.py` の関数をそのまま使っています。

## 結論

- 要約 (t は調整期間 / 検証期間):
  - 1時間足: 現行ルールは20年のデータ (Dukascopy 1時間足、コスト込み) で調整期間はマイナス、検証期間はプラス (t = -0.21 / 1.24)、表示の基準では「表示しない」。事前に決めた手順で選んだ「組み合わせ: 最長120本 + 値動きが過去1年の80%点を超えたら見送り」は両方の期間で現行ルールを上回り、推奨の条件を満たしました (t = 2.22 / 1.80)が、検証期間の t は 2 に届いていません。
  - 日足: 現行ルールは20年のデータ (Dukascopy 1時間足から作ったロンドン日足、コスト込み) で両方の期間でプラスだが t < 2 の期間あり (t = 0.94 / 1.60)、表示の基準では「表示しない」。改善案で推奨の条件を満たすものはなく、現行ルールのままとします。
- **1時間足ルール (金利差 + 5日間の流れ)**
  - Dukascopy 1時間足: 調整期間 (〜2016) 11743 回・1回平均 -1.2 pips・t = -0.21、検証期間 (2017〜) 8001 回・1回平均 +0.7 pips・t = 1.24 → 調整期間はマイナス、検証期間はプラス。本番のコストだけなら 調整 +0.2 pips (t = 1.55)、検証 +1.1 pips (t = 1.75) → 両方の期間でプラスだが t < 2 の期間あり。3年ごとの区切りでは 8 期間中 3 期間でプラス。
  - research/trade.md と同じ表示の基準 (Dukascopy 1時間足): 現行ルールは「表示しない」 (本番のコストだけなら「表示しない」)、候補は「表示しない」 (本番のコストだけなら「採用」(両方の期間で t ≥ 2))。
  - 改善案: 調整期間で最もよかった「組み合わせ: 最長120本 + 値動きが過去1年の80%点を超えたら見送り」は検証期間と他の条件も満たしたので、変更を推奨します。
- **日足ルール (金利差)**
  - Dukascopy 1時間足から作ったロンドン日足: 調整期間 (〜2016) 2282 回・1回平均 +1.1 pips・t = 0.94、検証期間 (2017〜) 1055 回・1回平均 +14.6 pips・t = 1.60 → 両方の期間でプラスだが t < 2 の期間あり。本番のコストだけなら 調整 +3.5 pips (t = 1.30)、検証 +16.8 pips (t = 1.90) → 両方の期間でプラスだが t < 2 の期間あり。3年ごとの区切りでは 8 期間中 5 期間でプラス。
  - Yahoo 日足: 調整期間 (〜2016) 1945 回・1回平均 +2.4 pips・t = 1.27、検証期間 (2017〜) 1084 回・1回平均 +19.4 pips・t = 2.04 → 両方の期間でプラスだが t < 2 の期間あり。本番のコストだけなら 調整 +2.4 pips (t = 1.27)、検証 +19.4 pips (t = 2.04) → 両方の期間でプラスだが t < 2 の期間あり。3年ごとの区切りでは 8 期間中 5 期間でプラス。
  - research/trade.md と同じ表示の基準 (Dukascopy 1時間足から作ったロンドン日足): 現行ルールは「表示しない」 (本番のコストだけなら「表示しない」)、候補は「表示しない」 (本番のコストだけなら「表示しない」)。
  - 改善案: 調整期間で最もよかった「組み合わせ: 値動きが過去1年の中央値以下のときだけ + 過去20日間の流れも同じ向きのときだけ」は推奨の条件を満たさなかったので、変更しません。

## データと方法

- 1時間足: Dukascopy の1時間足 (買値・売値の中間、各1時間の終わりの売値−買値の差を記録) 2003-05-04〜2026-08-31、7ペア計 1,010,400 本。本番が使う Yahoo の1時間足は直近約2.8年しかありません。
- 日足: Yahoo の日足 (2000-11-27〜2026-09-24、7ペア計 41,873 本、2002年から) と、Dukascopy の1時間足からロンドン時間の1日ごとに作った日足 (2003-05-05〜2026-08-31、7ペア計 42,180 本)。本番の日足の売買プランはロンドン時間の0時に発行され、1時間足の価格で決済するので、ロンドン日足の方が本番の取引に近く、Yahoo の日足は2011年から終値が「その日の始めの価格」になっている問題があります (下の「確認」)。日足のルールは両方で確かめ、改善案の選択はロンドン日足の調整期間で行いました。
- 期間: 調整期間 = 2016年末まで、検証期間 = 2017年1月から最後まで (エントリーの日付で分割)。
- エントリーは足の終値、損切り・利確は ATR (14本) の倍数、最長保有本数で時間決済、1本の足の中で損切りと利確の両方に届いたら損切り、損切り・利確の先で始まった足はその始値で決済 (`research_trade.simulate`)。1ペアにつき同時に1つのポジションだけ。
- コスト: 1回の取引ごとに、本番の往復コスト (USDJPY 0.5、EURJPY 0.7、GBPJPY 1.3、AUDJPY 0.9、EURUSD 0.5、GBPUSD 0.9、AUDUSD 0.7 pips) と、Dukascopy が記録した売値−買値の差 (エントリーの足の終わりで半分、決済の足の終わりで半分) の大きい方。記録の誤りを除くため、差はペアの中央値の20倍で頭打ちにしました。Yahoo の日足は差の記録がないので本番のコストだけです。Dukascopy の1時間足の終わりの差の中央値 (pips、調整期間 / 検証期間): USDJPY 1.00 / 0.40、EURJPY 1.70 / 0.80、GBPJPY 3.00 / 1.70、AUDJPY 2.00 / 0.70、EURUSD 1.00 / 0.30、GBPUSD 1.50 / 0.90、AUDUSD 1.60 / 1.00。
- スワップ: その時点で知り得た短期金利 (FRED、公表の遅れを考慮) の差から、業者の取り分 0.5% を引いたものを保有時間に比例して加算。
- 統計: 平均pips はコスト・スワップ込みの1回あたり。t は月ごとの損益 (全ペア合計の R、R は損切り幅を1とした損益) の t 値で、同じ時期に複数のペアで持つ取引 (円安・円高で一緒に動く) を独立に数えないためのものです。最大DD は全ペア合計の損益の最大の落ち込み。
- VIX は FRED の終値を2日遅らせて使いました (公表の遅れ)。実現ボラティリティ・200日移動平均・VIX は各足の終わりまでのデータだけで計算。

### 事前に決めた改善案と採否の基準

結果を見る前に次の変更を1つずつ試すと決め、選択には調整期間だけを使いました。

- 1時間足 (21通り): 金利差0.5%以上、金利差2%以上 (= 日足ルールとの一致)、金利差3%以上、流れ: 過去24時間、流れ: 過去72時間、流れ: 過去240時間、損切り ATR×2、損切り ATR×4、利確 ATR×2、利確 ATR×4、利確なし、最長12本、最長48本、最長120本、21〜23時 (UTC) に確定する足では入らない (ロールオーバー前後)、8〜17時 (UTC) に確定する足でだけ入る (ロンドン・NY時間)、値動きが過去1年の80%点を超えたら見送り、値動きが過去1年の中央値以下のときだけ、200日移動平均と同じ向きのときだけ、VIX 25以上なら見送り、VIX が5営業日前より20%以上高ければ見送り
- 日足 (15通り): 金利差1%以上、金利差3%以上、損切り ATR×2.5、損切り ATR×6、利確 ATR×4、利確なし、最長10本、最長20本、過去5日間の流れも同じ向きのときだけ (= 1時間足ルールとの一致)、過去20日間の流れも同じ向きのときだけ、200日移動平均と同じ向きのときだけ、値動きが過去1年の80%点を超えたら見送り、値動きが過去1年の中央値以下のときだけ、VIX 25以上なら見送り、VIX が5営業日前より20%以上高ければ見送り
- 組み合わせ (1通りだけ): 種類 (金利差の基準・流れの期間・損切り・利確・保有期間・時間帯・値動きの大きさ・トレンド・リスクオフ) ごとに、調整期間で現行ルールを上回った変更のうち t が最も高いものを選び、その中で調整期間の t が高い2種類をまとめて1つの案にする (多く組み合わせるほど調整期間に合わせすぎるため2種類まで)。
- 候補: 調整期間の取引が 150 回以上で、調整期間に現行ルールを平均pips と t の両方で上回った案のうち、調整期間の t が最も高いもの。
- 推奨の条件: 候補が検証期間でも平均pips と t の両方で現行ルールを上回り、検証期間で平均が改善したペアが 4/7 以上、どの1ペアを除いても検証期間で現行ルールを上回ること (1ペアだけの偶然でないこと)。日足は Yahoo 日足・ロンドン日足の両方で満たすこと。
- 「1時間足と日足のシグナルの一致」は、1時間足では「金利差2%以上」(日足ルールの条件) と同じになり、日足では「過去5日間 (≒120時間) の流れも同じ向き」と同じになるので、それぞれその案として数えています。
- 試した案の数: 1時間足 22 通り、日足 16 通り (組み合わせを含む、現行ルールを除く)。

## 推奨

- 1時間足: 調整期間で最もよかった変更は「組み合わせ: 最長120本 + 値動きが過去1年の80%点を超えたら見送り」(金利差1.0%以上、L=120、損切り ATR×3.0、利確 ATR×3.0、最長120本 + vol80)。
  - Dukascopy 1時間足: 調整 -1.2 → +2.5 pips (t -0.21 → 2.22)、検証 +0.7 → +2.1 pips (t 1.24 → 1.80)。検証期間で平均が改善したペア 6/7 (USDJPY・EURJPY・GBPJPY・AUDJPY・GBPUSD・AUDUSD)、どの1ペアを除いても検証期間で上回るか: はい。判定: 合格
  - **変更を推奨**
  - 補足 (事後の確認、採否には使っていません): 組み合わせの一部「最長120本」だけの場合 — Dukascopy 1時間足: 調整 ○・検証 ○・改善したペア 6/7・1ペア除外 ○ → 推奨の条件を満たす。
  - 補足 (事後の確認、採否には使っていません): 組み合わせの一部「値動きが過去1年の80%点を超えたら見送り」だけの場合 — Dukascopy 1時間足: 調整 ○・検証 ○・改善したペア 3/7・1ペア除外 × → 推奨の条件を満たさない。
  - `aifx/trade.py` の `RULES["1h"]` を `hold`: 24 → 120 に変更。加えて `rule_signal` に、直近120本の対数変化の標準偏差が、その前の6,000本の同じ値の80%点を超えたら見送る判定を足し、`forecaster.py` から `plan()` に渡す足を6,121本以上にする必要があります (今は `fit_bars` = 3,000本)。

## 注意

- Dukascopy の価格は1社の気配値で、国内の業者の価格・約定とは少し違います。スプレッドは各1時間の終わりの値で、損切りが1時間の途中で約定するときの実際の差とは異なります。
- スワップは金利差 (3か月物・翌日物の金利) から一定の取り分を引いた近似で、業者ごとの実際のスワップや水曜日の3日分の付与は再現していません。
- 検証期間は1つの時期です (2017年以降)。調整期間で選んだ案が検証期間でも良いかは、偶然にも左右されます。
- 現行の1時間足ルールは Yahoo の1時間足 (2023年12月〜2025年8月) で選ばれたので、この検証期間の一部はすでに選択に使われています。検証期間の現行ルールの成績はその分よく見えている可能性があり、改善案との比較は現行ルールに有利です。
- 改善案の一覧、組み合わせの作り方、候補の選び方と推奨の条件は、Dukascopy のデータで結果を見る前に決めました (プログラムの動作確認は Yahoo のデータで行いました)。「補足 (事後の確認)」の行は結果を見た後に加えたもので、採否には使っていません。
