# 時間帯の偏りは本物か: Yahoo と Dukascopy の仲値、2004年からの検証

## 結論

- **Yahoo の為替の価格はペアによって売値 (bid) か、仲値に一定の差を足した価格です。** 重なる期間の同じ足で比べると、円のペア (USDJPY・EURJPY・GBPJPY・AUDJPY) では売値 (bid) です。Yahoo − 仲値 は半スプレッドとともに動き (傾き -0.73、−1 なら売値そのもの)、中央値 -0.40 bp (半スプレッド 0.34 bp)、一番近いのは売値 (87% の足)。ロールオーバー前後 (ニューヨーク時間16〜17時台) はスプレッドが広がり、差も -2.52 bp (半スプレッド 2.34 bp) に広がります。EURUSD・GBPUSD・AUDUSD では仲値に一定の差 (EURUSD +2.83・GBPUSD +0.33・AUDUSD +2.35 bp) を足した価格で、スプレッドが広がっても差はほとんど変わらず (傾き +0.05、16〜17時台の差 +2.90・+0.33・+3.28 bp)、ロールオーバー前後の値動きも仲値に一番近くなります。
- **古い気配:** USDJPY・EURJPY・GBPJPY・AUDJPY・GBPUSD・AUDUSD は終値が前の足から動かない足が 0.3%〜1.8% (Dukascopy 0.1%〜0.5%) と少なく、古い気配は目立ちません。EURUSD の Yahoo は終値が前の足から動かない足が 9.0% (17時台 21.0%) と、Dukascopy (0.3%) より多く、古い気配が残ることがあります。金曜日の取引終了後には Yahoo だけに1本だけの気配の足が出ます (後述)。
- **偏りのうち、ロールオーバーの前後の時間 (16時・18時に始まる足) の分は、円のペア (USDJPY・EURJPY・GBPJPY・AUDJPY) の Yahoo (売値) だけに出る見かけです。** Yahoo で計算した方向 (本番と同じ) を同じ足の仲値で採点すると、これらのペアの16時・18時の足 (3,349回) は Yahoo 68.7%・売値 68.0% に対して仲値 50.9%、うち確度: 高 (715回) は Yahoo 78.1% に対して仲値 54.1% でした。16時台にスプレッドが広がって売値が下がり、18時台に戻って売値が上がる動きで、仲値には偏りがありません。
- **ロールオーバーの時刻を含む足 (17時に始まる足) の偏りは仲値にもあります。** 17時の足は Yahoo 68.7%・仲値 66.1% (2,176回)、うち確度: 高 は Yahoo 79.2%・仲値 79.0% (570回)。ほかの時間は Yahoo 52.5%・仲値 52.4% で差がありません。17時の足の動きは、受け渡し日が1日 (水曜日は3日) 延びる分の金利差 (スワップポイント) とともに大きくなります (ペア×年の平均で傾き 1.27・相関 0.65。傾き 1 なら短期金利差どおり)。このずれはポジションを持ち越す人が受け取る (払う) スワップと同じ額で相殺されるため、**価格の表示としては本物でも、売買で得られるものではありません。**
- そのため確度: 高 (|t| ≥ 4) の的中率は、重なる期間で Yahoo 76.6% に対して仲値 63.6% (1,435回)、方向を示した回全体では Yahoo 58.1%・仲値 53.7% です。確度: 高 の平均の動きから実際のスプレッドを引くと -2.43 bp、スワップも含めると -3.10 bp です。
- **20年の仲値 (Dukascopy、2004年〜) でも効果はありますが、強さは金利差しだいです。** 方向を示した回の的中率は調整期間 (〜2016) 53.6%・検証期間 (2017〜) 54.5%、確度: 高 は 61.5% (3,678回)・64.4% (4,181回)。確度: 高 が年50回以上あった年の的中率は 45.3% (2005年) 〜 73.9% (2023年) で、2009〜2010、2016 年は確度: 高 が年50回に届きません。ずれの大きさが金利差とともに変わるため、金利差が大きい年ほど偏りがはっきりし、金利がゼロ近くに並んだ年はほとんど確度: 高 になりません。
- **的中率90%を安定して出せる基準はありませんでした。** 本番が予測する足 (市場が開いている足) の Yahoo で、調整期間で選んだ |t| ≥ 8 (調整 92.3%、65回、95%下限 83.2%) は検証期間で 82.2% (45回)、20年の仲値では同じ基準で調整 0回・検証 80.8% (516回)。|t| を上げるほど回数が減り (検証期間で数十回、全体の0.1%程度)、的中率は80%台で頭打ちです。15分足で一番高いのは |t| ≥ 5 の 89.9% (169回、95%下限 84.4%) ですが、直近約60日しかなく調整期間で確かめられません。そのため「確度: 最高」は追加しません。
- 本番の区分 (確度: 中・高) はそのままでよいと考えます。ただし研究 (research/direction.md) の確度: 高 の成績 (調整 74.9%・検証 79.8%) は、本番が予測しない金曜日の取引終了後の足を含んでおり、本番が予測する足だけでは調整 73.7% (629回)・検証 78.4% (882回) です。画面の注意書きは「偏りはロールオーバー (日本時間の朝6〜7時) の気配の仕組みによるもので、スプレッドとスワップを差し引くと利益になりません」とするのがよいと考えます (詳しくは「4. 推奨」)。

## 4. 推奨

新しい基準は、調整期間で的中率90%に届く最小の |t| (30回以上) として選び、検証期間とDukascopyの仲値で確かめました。採用の条件は、本番のデータ (Yahoo、本番が予測する足) の調整・検証の両方で90%以上、検証期間で200回以上、仲値の2004〜2016年・2017年〜の両方で90%以上です。

| データ | 調整期間で選んだ基準 | 調整: 回数 / 的中率 | 検証: 回数 / 的中率 | 両方の期間で90%以上になった基準 |
|---|---|---|---|---|
| Yahoo 1時間足 (本番が予測する足) | \|t\| ≥ 8 | 65 / 92.3% | 45 / 82.2% | なし |
| Yahoo 1時間足 (すべての足) | なし | 0 / — | 0 / — | なし |
| Dukascopy 仲値 (2004〜) | なし | 0 / — | 0 / — | なし |

条件の確認 (Yahoo、本番が予測する足で選んだ基準): 調整期間で基準が決まる ○、検証期間で90%以上 ×、検証期間で200回以上 ×、仲値 2004〜2016 で90%以上 ×、仲値 2017〜 で90%以上 ×

1. **本番の区分はそのまま (|t| ≥ 2 で方向、|t| ≥ 4 で確度: 高)。** 確度: 高 は本番が予測する足の Yahoo で 調整 73.7%・検証 78.4%、20年の仲値でも 61.5%・64.4% と、偶然より明らかに当たります。表示する検証の的中率は、本番が予測する足 (市場が開いている足) で数えた値にするのが正確です。なお、実際に売買できる価格 (仲値) の向きを示したい場合は、円のペア (USDJPY・EURJPY・GBPJPY・AUDJPY) の16時・18時に始まる足 (売値だけの動き) の方向を外す選択肢があります (重なる期間の確度: 高 で、外す 715回は仲値で 54.1%、残る 720回は仲値で 73.1%・Yahoo で 75.1%)。ただし画面のチャートと答え合わせは Yahoo の価格 (円のペアでは売値) なので、外すと画面上の的中率は下がります。
2. **確度: 最高 (的中率90%) は追加しない。** 条件を満たす基準がなく、|t| を上げても的中率は80%台で、回数は検証期間で数十回まで減ります。
3. **画面の注意書き (案):** 「方向の偏りの大部分は、ニューヨーク時間17時 (日本時間の朝6〜7時) のロールオーバー前後の価格の仕組みによるものです。円のペアの表示価格 (Yahoo) は売値で、この時間はスプレッドが広がって売値が下がり、その後に戻ります。ロールオーバーでは受け渡し日が延びる分だけ価格がずれ (水曜日は3日分)、その分はスワップで相殺されます。表示される価格の向きとしては当たりますが、スプレッドとスワップを差し引くと売買の利益にはなりません。」

## 方法の注記

- 方向の計算は aifx/season.py と同じ規則を、全時点をまとめて計算できる形に書き直したものです。Dukascopy の USDJPY, EURJPY で無作為に選んだ日の 831時点を season.slot_stats / bar_drift で計算し直し、t 値の差は最大 3.6e-13、方向を示すかどうかの食い違いは 0 件でした。Yahoo では research/direction.md の数字 (1時間足 8,493回・61.1%、確度: 高 1,069回・79.8% など) をそのまま再現します。
- 各時点の統計は、予測する日の0時 (UTC) より前の6,000本だけから作ります (先読みなし)。週明けの窓開けなど、1時間より空いた足の動きは統計から除きます。
- Dukascopy は1時間ごとの売値と買値のローソク足 (取引のない週末・祝日の時間は欠ける) から、仲値 = (売値 + 買値) / 2、スプレッド = 買値 − 売値 (終値の時点) を作りました。2004年から、6,000本の窓がそろう時点を使います。
- 「スプレッド後」は、予測の時点の買値で買い (売りなら売値で売り)、次の足の終値の売値で売る (買値で買い戻す) ときの損益です。「スワップ後」は、ロールオーバーをまたぐ足 (ニューヨーク時間17時に始まる足) に、短期金利の差 (FRED、公表の遅れを考慮した当時の値) ÷ 360 (水曜日は3日分) のスワップを加えたものです (銀行間の条件。個人向けのスワップはもっと不利です)。
- 的中率は動きがゼロの回を除いて数え、95%下限は Wilson の区間です。t は週ごとに全ペアの結果を合計して計算しています。
- 週の上位 N 枠: その日の統計で、曜日×時間の168枠のうち |t| が大きい N 枠に入る足だけ方向を示します。15分足は約60日分しかなく、曜日×15分の枠は15本に届かないため、15分足の方向はすべて「15分」の枠 (曜日なし) から出ています。
- 計算時間 12 秒 (`python -m aifx.research_season_long`)。
